# Офис — мини-приложение Telegram поверх улья

- `app/` — служба на Python (только стандартная библиотека): проверка входа из Telegram, чтение реестра улья, список проектов.
- `web/` — страница приложения (без сборки), пиксельные аватары-заглушки в `web/avatars/`.
- `deploy/` — юнит systemd и образец `.env`.
- `tests/` — проверки: `python3 -m unittest discover -s tests`.
- Правила проекта — `CLAUDE.md`, задания Майклу — `docs/для-майкла.md`, изменения сервера — `ЖУРНАЛ.md`.

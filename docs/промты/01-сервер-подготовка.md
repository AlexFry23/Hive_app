- Копия: `cp -a /opt/caddy/Caddyfile /opt/caddy/Caddyfile.bak-2026-11-01-app`.

1. Пользователь и папка приложения
- `useradd --system --home-dir /opt/office-app --shell /usr/sbin/nologin office-app`
- `install -d -o office-app -g office-app -m 0750 /opt/office-app /opt/office-app/data`

3. Адрес приложения в Caddy
- Добавить в конец /opt/caddy/Caddyfile:
